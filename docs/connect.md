# Подключение MCP-сервера Sitebill

Страница продукта: https://www.sitebill.ru/mcp-server/

## Что нужно

- Сайт на платформе. Бесплатный демо-сайт «Риелтор Старт»: https://www.sitebill.ru/client/cart.php?a=add&pid=126
- Адрес сервера: адрес вашего сайта на платформе и `/mcp`, например `https://ваш-сайт.etownpro.ru/mcp`.
- Включённый MCP: в админке сайта «Настройки → ИИ-агенты».
- Токен: в кабинете, раздел «ИИ-агенты». Показывается один раз. Токен действует только на домене своего сайта.

Два вида токена:

| Токен | Права |
|---|---|
| Персональный (сотрудника) | как у сотрудника в кабинете; может быть только для чтения или с записью; CRM доступна |
| Ключ организации | только чтение, без CRM |

## Claude Code

Плагин (скилл и сервер):

```bash
/plugin marketplace add rumantic/claude-skills-real-estate
/plugin install sitebill-realty@claude-skills-real-estate
```

Переменные окружения для плагина:

```bash
export SITEBILL_MCP_URL="https://ВАШ-САЙТ/mcp"
export SITEBILL_MCP_TOKEN="ВАШ_ТОКЕН"
```

Только сервер, без плагина:

```bash
claude mcp add --transport http realty https://ВАШ-САЙТ/mcp --header "Authorization: Bearer ВАШ_ТОКЕН"
```

Проверка: запустите `claude` и спросите «какие инструменты доступны на сервере realty?». Должно быть 16 инструментов
(без инструментов записи, если токен только для чтения).

## Claude Desktop

Через мост `mcp-remote` (нужен Node.js). Раздел Developer → Edit Config:

```json
{
  "mcpServers": {
    "realty": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://ВАШ-САЙТ/mcp", "--header", "Authorization: Bearer ВАШ_ТОКЕН"]
    }
  }
}
```

Перезапустите приложение.

## Cursor

Файл `.cursor/mcp.json` в проекте или `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "realty": {
      "url": "https://ВАШ-САЙТ/mcp",
      "headers": { "Authorization": "Bearer ВАШ_ТОКЕН" }
    }
  }
}
```

## ChatGPT

Подключение через OAuth в разработке: токен в ChatGPT пока подключить нельзя.

## Если не работает

| Ответ сервера | Причина |
|---|---|
| 401 «Не передан токен» или «Неверный или отозванный токен» | нет заголовка `Authorization: Bearer`, токен отозван или ошибка в нём |
| 401 «Токен выпущен для другого аккаунта» | токен от другого сайта: используйте адрес того сайта, где он выпущен |
| 403 «MCP-сервер не включён» | включите в «Настройки → ИИ-агенты» |
| 403 «аккаунт временно отключён» | сайт приостановлен |
| 404 | неверный адрес: нужен `https://<домен сайта>/mcp` |
